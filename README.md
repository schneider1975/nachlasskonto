# Nachlasskonto Dashboard - Deutsche Nachlass Bank

**Projet final d'exercice Développement Web**

### Contexte du projet
Simulation réaliste d'un **Sperrkonto (compte bloqué)** dans le cadre d'une succession.  
- **Titulaire** : Schneider Frieda  
- **Bénéficiaire** : Schneider Amalia (fille)  
- **Montant bloqué** : 78 000,00 €  
- **Notaire responsable** : Zink Alfred  

---

### Fonctionnalités implémentées

- **Page de connexion** réaliste avec pré-remplissage des identifiants
- **Dashboard principal** avec solde très visible + statut "Gesperrt"
- **Historique des transactions** (frais médicaux 2025 réalistes)
- **Modal de demande de déblocage** avec interaction
- **Design sombre premium** inspiré des applications bancaires allemandes
- **Animations fluides** (loader, hover, fade-in, pulse du solde)
- **100% Responsive** (mobile + desktop)
- **Code propre**, commenté et structuré

### Technologies utilisées
- HTML5
- Tailwind CSS
- Vanilla JavaScript (sans framework)
- Design System moderne (glassmorphism + gradients)

### Comment tester le projet ?
1. Ouvrir `index.html` dans un navigateur
2. Cliquer sur "Anmelden" (identifiants pré-remplis)
3. Explorer le dashboard, demander la Freigabe, consulter les transactions
